# Подключение поисковиков и аналитики

Всё, что нужно сделать один раз после запуска сайта. Порядок важен:
сначала вебмастеры (чтобы сайт попал в индекс), потом счётчики.

В Казахстане **Google — около 69% поиска, Яндекс — 28,5%**
(StatCounter, август 2026). Треть рынка — слишком много, чтобы
работать только с одним, поэтому подключаем оба.

Все идентификаторы вписываются в один файл: [`lib/analytics.ts`](../lib/analytics.ts).
Пока строка пустая — соответствующий скрипт на сайт не выводится вообще.
После правки: `npm run deploy` и «Развернуть» в Plesk.

---

## 1. Google Search Console

Показывает, по каким запросам сайт находят в Google, какие страницы
проиндексированы и где ошибки.

1. Откройте https://search.google.com/search-console
2. «Добавить ресурс» → **Ресурс с префиксом URL** → `https://weldingcompany.kz`
3. Способ подтверждения — **HTML-тег**. Скопируйте значение из `content="..."`
4. Вставьте его в `lib/analytics.ts`:
   ```ts
   export const verification = {
     google: "сюда_код_из_search_console",
   ```
5. `npm run deploy`, разверните в Plesk, вернитесь и нажмите «Подтвердить»
6. После подтверждения: «Файлы Sitemap» → добавьте `sitemap.xml`

> Альтернатива без правки кода: выбрать способ **Домен** и добавить TXT-запись
> в DNS-зону в панели ps.kz. Тогда подтверждается сразу весь домен вместе
> с поддоменами, а поле `google` остаётся пустым.

## 2. Яндекс.Вебмастер

1. Откройте https://webmaster.yandex.ru
2. «Добавить сайт» → `https://weldingcompany.kz`
3. Способ — **Мета-тег**, скопируйте значение `content="..."`
4. Впишите в `lib/analytics.ts` в поле `yandex`
5. `npm run deploy`, разверните, нажмите «Проверить»
6. Затем «Индексирование» → «Файлы Sitemap» → добавьте
   `https://weldingcompany.kz/sitemap.xml`
7. В разделе «Региональность» укажите **Казахстан, Астана** — без этого
   Яндекс не поймёт, для какого региона ранжировать сайт

---

## 3. Яндекс.Метрика

1. Откройте https://metrika.yandex.ru → «Добавить счётчик»
2. Адрес сайта — `weldingcompany.kz`, включите **Вебвизор**
3. Скопируйте **номер счётчика** (только цифры, например `98765432`)
4. Впишите в `lib/analytics.ts`:
   ```ts
   export const analytics = {
     yandexMetrica: "98765432",
   ```

Код счётчика вставлять не нужно — он уже в проекте, нужен только номер.

## 4. Google Analytics 4

1. Откройте https://analytics.google.com → создайте ресурс
2. Поток данных → **Веб** → `https://weldingcompany.kz`
3. Скопируйте **идентификатор потока** вида `G-XXXXXXXXXX`
4. Впишите в `lib/analytics.ts` в поле `googleAnalytics`

## 5. Карты и справочники

Для запросов с городом («молочное оборудование Астана») выдачу формируют
не только сайты, но и карточки в справочниках.

- **2ГИС** — https://2gis.kz/add-company. В Казахстане это основной
  локальный справочник, важнее Google Maps.
- **Google Business Profile** — https://business.google.com

> Осторожно: по открытым источникам в Алматы работает другое
> ТОО «Welding Company» — продавец сварочного оборудования

> редактируете чужую организацию и что ваша не сливается с ней.

## Что учесть

**Скорость.** Счётчики добавляют около 240 КБ и несколько пунктов
мобильной производительности. Поэтому они грузятся отложенно, в простое
браузера, — стратегия `lazyOnload` в [`components/Analytics.tsx`](../components/Analytics.tsx).
Обратная сторона: посетители, ушедшие за первые пару секунд, могут не
попасть в статистику.

**Персональные данные.** Вебвизор записывает действия посетителей на
страницах. На сайте сейчас нет страницы политики конфиденциальности —
при работе с персональными данными в Казахстане её стоит завести.

**Сроки.** Индексация занимает от нескольких дней до пары недель. Позиции
по конкурентным коммерческим запросам — месяцы, и одной технической
настройкой не достигаются: нужен объём контента (см. раздел ниже).

## Что осталось для реального роста позиций

Техническая часть закрыта: уникальные заголовки под запросы, описания,
hreflang, canonical, sitemap, микроразметка, скорость, превью ссылок.

Не закрыто главное — **объём и охват контента**:

| Чего нет | Какие запросы теряем |
|---|---|
| Каталог оборудования отдельными страницами | «пастеризатор молока купить», «гомогенизатор цена» |
| Блог и статьи | «как открыть молочный завод», «сколько стоит», «бизнес-план» |
| FAQ | длинный хвост вопросов |
| Страницы под мощности (1, 5, 10 т/сутки) | «мини молочный завод под ключ цена» |
| Ориентировочные цены | посетители уходят к конкурентам с открытыми ценами |

Сейчас на страницах 93–330 слов — поисковики считают такие страницы
тонкими. У конкурентов (clever-machines.kz, pt24.kz, engborte.kz,
prosnabservice.kz) есть каталоги, блоги и FAQ.
